## How to use this

Answer what you can. Where you do not know, write **"don't know"** rather than
guessing - a guess that reaches the system as a fact is worse than a blank,
because nobody will ever question it again.

We will walk the store with you afterwards and confirm the answers on site.
That walk is the part that decides whether the system is trusted, so nothing
here needs to be perfect on paper.

Anything marked **★** we cannot start without.

## 5. Units and packs - the section that matters most

> This is where inventory systems fail. If we record that a sack is 50 kg and it
> is really 25 kg, every figure the system ever produces about that item is
> wrong, and nobody will find out for months.

| # | Question | Answer |
|---|---|---|
| 5.1 | For each item, what is the **smallest unit** you want to measure in - grams, millilitres, or each? ★ | |
| 5.2 | Does any item arrive in **more than one pack size**? (e.g. sugar in 1 kg packs and 50 kg sacks) ★ | |
| 5.3 | For each pack, exactly how many small units does it contain? ★ | |
| 5.4 | Are any packs sold by an approximate weight - "about 5 kg" - rather than an exact one? | |
| 5.5 | Do you ever receive a **part pack** - half a sack, three of a case of twelve? | |
| 5.6 | Which items are bought by weight at the market rather than by pack? | |

> the real losses. We need both numbers, and they are yours to set.
